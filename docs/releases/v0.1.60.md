# v0.1.60

This release scopes bandwidth policy buckets to the inbound that owns the
connection. A global node ceiling configured on one inbound no longer limits
another inbound on the same Agent.

The release includes regression coverage for two inbounds on one Agent:

- one inbound capped at 100 Mbps;
- one inbound without a node ceiling.

The tests verify that the first remains capped while the second remains
uncapped, including after control-plane allocation updates.
